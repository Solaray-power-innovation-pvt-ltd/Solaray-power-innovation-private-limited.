SOLARAY WEBSITE
===============
Files:
- index.html
- style.css
- script.js

Publish free with GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository, e.g. solaray-website.
3. Upload index.html, style.css and script.js.
4. Open Settings > Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will provide your free public website URL.

To change phone number, search for 8837332798 in index.html and replace it.
